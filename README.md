# 🚀 Meu Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio profissional. O objetivo é demonstrar minhas habilidades técnicas em desenvolvimento Front-end e exibir meus projetos principais.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **CSS3:** Estilização moderna com Flexbox, Grid e animações.
- **JavaScript:** Manipulação de DOM e lógica de interatividade.
- **Font Awesome:** Ícones sociais e de interface.

## 📱 Funcionalidades
- [x] Design 100% Responsivo (Desktop, Tablet e Mobile).
- [x] Menu Mobile com fechamento inteligente (clique fora/scroll).
- [x] Seção de Jornada (Timeline) de aprendizado.
- [x] Animações de revelação ao rolar a página (Scroll Reveal).
